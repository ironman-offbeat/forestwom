# Forestwom

**성남시 건축협의 조경 검토 웹앱.** PDF 접수 → 소유자가 ChatGPT에서 분석 → 관리자 결과 PDF·JSON 등록 → 결과 페이지 공개로 운영합니다. 유료 AI API와 GAS는 사용하지 않습니다.

[웹앱 열기](https://forestwom.2hayoung.com) · [자동 검증·배포 상태](https://github.com/ironman-offbeat/forestwom/actions)

## 사용 순서

1. 입력 페이지에서 PDF·도면 이름·요청 메모를 등록하고 결과 링크를 보관합니다.
2. 원본 검증과 Drive 저장이 완료되면 소유자에게 Slack 알림을 전송합니다. Slack 미연결/실패는 관리자 화면에서 재전송합니다.
3. 관리자는 `/#/admin`에서 로그인 없이 원본과 분석 요청문을 받아 ChatGPT에 첨부합니다.
4. 분석 결과 PDF·JSON을 등록하고 근거·최신성을 확인한 후 공개합니다. 이용자는 결과 링크에서 의견서를 확인하고 PDF를 받습니다.

[접수·관리자·Slack 연결 안내](docs/REQUEST_WORKFLOW.md) · [작업계획](docs/WORK_PLAN_V3.md)

### 기존 원본 대조·검산 도구 (`/#/review`)

1. PDF 선택 또는 가상 자료 버튼 클릭.
2. 각 수치의 추출 후보를 선택하고 근거 페이지를 열어 원본 대조. 수정값 및 검수 사유 입력 후 확정.
3. 사건 적용기준일, 법령 원문 확인일, 확인 기록 및 적용 범위를 검토.
4. 의견서에서 검산 결과와 보류·보완사항 확인. 담당자 검토 기록 및 인쇄/PDF 저장.

5. **결과 PDF 다운로드**로 의견서를 받거나 **저장소에 넣어두기**로 원본·의견서 PDF·검토 기록을 함께 저장.
6. **저장소 보기**는 Google Drive 폴더로 이동. **저장한 검토 다시 열기**는 앱에서 원본과 수치를 복원하고 재검수.

PDF 판독은 브라우저에서 수행합니다. 저장 버튼을 누를 때만 도면과 검토 기록이 Vercel 서버를 통해 소유자의 Drive로 전송됩니다. 유료 AI API, GAS, 외부 CDN, 통계 수집, localStorage/IndexedDB 저장은 사용하지 않습니다. 저장하지 않은 내용은 새로고침하면 사라집니다.

앱 이용자는 Google 로그인을 하지 않습니다. 소유자는 **최초 Google 연결**이 필요합니다. [연결 절차](docs/GOOGLE_DRIVE_SETUP.md)를 따르세요. 연결 전에도 원본 검토와 PDF 다운로드는 동작합니다. 링크 편집 권한은 API 인증을 대신하지 않습니다.

## 실행

Node.js 24 LTS 권장. 잠금 파일을 사용합니다.

```sh
npm ci
npm run dev
```

표시된 로컬 주소를 브라우저에서 엽니다. 배포 빌드: `npm run build`. 생성되는 `dist/`는 하위 경로를 포함한 정적 호스팅에서 동작합니다. Drive 저장은 Vercel의 `api/storage.mjs`와 소유자 OAuth 환경 변수가 필요합니다. `npm run dev`에서는 검토와 PDF 출력이 가능하며 저장 API는 Vercel 환경에서 실행합니다. GitHub Pages는 운영 Vercel API를 호출합니다.

## 테스트

```sh
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```

가상 자료는 `npm run fixtures`로 재생성합니다. 정상(1000㎡/2000㎡/160㎡/80㎡/20㎡), 미달, 상충(대지 1000/1200㎡), 텍스트 없는 스캔 모사, 혼합, 손상 PDF가 포함됩니다. 한글 가상 PDF도 파일 선택으로 시험할 수 있으며 선택적 재생성은 `python scripts/korean-fixture.py` (PyMuPDF 필요)입니다. 앱 실행에는 Python이 필요 없습니다. 실제 민원자료는 포함하지 않습니다. 한글 CAD PDF 전체 판독 품질을 검증했다고 주장하지 않습니다.

## 자동 검산 범위

- 대지 300㎡ 이상, 면제·특례가 없는 일반 건축물. 옥상·벽면녹화 및 특수공간 산입 없음.
- 연면적에 따른 조경 의무면적, 식재 의무면적, 자연지반 최소면적의 수치 검산.
- 자동 추출은 라벨·단위가 확인되는 후보만 제공. 도형 면적 측정, 수목 기호 인식, OCR 없음.
- 스캔·혼합의 텍스트 부족 페이지는 전체 검토 보류. OCR은 향후 브라우저 로컬 방식과 재검수 절차를 갖춘 뒤 추가 가능.
- 수목 수량·규격, 배치, 공개공지, 심의, 면제·특례, 옥상·벽면은 별도 수동 검토.
- 텍스트가 일부 존재하는 이미지 페이지를 완벽히 식별할 수 없으므로 페이지별 원본 대조가 필수.

## 법령·보안 제한

기존 프로젝트 자료·정오표는 미확보입니다. [법령 검증 장부](docs/LEGAL_REVIEW.md)에 공식 출처, 확인본 시행일, 상충 규칙 및 미확인 사항을 기록했습니다. 법령 최신성은 자동 보증되지 않습니다.

담당자 확인 기록은 검토 이력이며 전자결재는 아닙니다. 링크 편집 공유는 전용 저장소에만 적용합니다. 공개 편집된 저장본은 다시 열 때 수치·법령·담당자 확인을 다시 받습니다.

### 접수별 사건 검토표

관리자 접수 상세의 **사건 검토표 열기**에서 해당 접수 원본을 바로 대조할 수 있습니다.
소재지·관할·용도·용도지역·신청 유형·신청일·면제/특례·지구단위계획의 값과 확인 근거를 기록하고,
수치와 적용 기준을 확인하면 기존 조경·식재·자연지반 면적 3개 항목을 검산합니다.
미확인 사건 정보, 성남시 외 관할, 판독 보류 또는 적용 기준 미확인은 검산을 보류합니다.

**사건 검토표 저장**은 원본 파일을 새로 만들지 않고 기존 접수의 서명된 기록에 초안을 저장합니다.
서버에서 원본 해시와 실제 PDF 페이지 수를 확인하며, 다시 열 때 원본을 검증하고 검산을 다시 실행합니다.
같은 원본·규칙 버전이면 수치 확인 상태를 복원하고, 규칙 버전이 변경되면 수치·적용 기준 확인을 해제합니다.
사건 정보를 수정하면 적용 기준을 다시 확인해야 합니다. 담당자 초안 검토 기록은 재접속 시 다시 받습니다.

검토표는 공개 결과와 별개입니다. 저장만으로 접수 상태나 공개 PDF·JSON을 변경하지 않습니다.
항목별 법령·판정 기록, 보완 요청·추가 제출, 같은 데이터에서 결과 PDF·JSON 생성까지 지원합니다.
현재 관리자 접근 정책은 기존과 같으며 검토표도 관리자 상세 API에서 조회됩니다.

### 법령 판정·보완·결과 공개 (2026-11-28 기능 브랜치)

- 검토표의 **항목별 법령·판정**에 법령명·조항·시행일·원문 확인일·공식 링크·적용 사유와 도면 인용을 기록합니다. 판단 보류/기준 충족/미충족/해당 없음으로 구분하며, 사건 정보와 수치·적용 기준을 확인하기 전에는 확정 판정을 선택할 수 없습니다. 법령 자체를 자동으로 검색·확인하지는 않습니다.
- 관리자의 **보완 요청 게시**는 최종 법령 확인 없이 필요한 자료를 요청합니다. 이용자는 같은 결과 링크에서 보완 PDF를 제출합니다. 기존 원본은 보존하고 차수 식별자가 포함된 이름으로 추가합니다. 전체 원본 최대 10개·합계 100MB, 파일당 30MB·100페이지입니다. 요청은 사유를 남겨 취소할 수 있습니다.
- 보완 제출은 수치·사건 정보·적용 기준 확인과 항목 판정을 해제하고 소유자 Slack 알림을 시도합니다. 알림 실패 시 제출을 보존합니다. 수정본과 이전 원본의 상충은 담당자가 채택 사유를 기록합니다.
- 검토자와 내용을 저장한 뒤 **공개 결과 미리보기 → 미리보기 PDF 생성 → 대조 확인 → 검토표 결과 공개**를 사용합니다. 같은 결과 데이터에서 화면·PDF·JSON을 생성합니다. 미완료 보완 요청, 미확인 법령, 바뀐 원본·검토표는 공개를 차단합니다. 외부 PDF·JSON 등록 경로도 유지합니다.
- 이전 공개 결과는 원래 원본 목록과 함께 보존합니다. 보완 중에는 이전 결과임을 표시합니다. 과거 결과의 조회와 새로운 결과의 법령 최신성 검사는 분리됩니다.

위 기능은 PR에서 검증한 구현 내용이며 production 반영 여부는 배포 상태를 별도로 확인합니다.
