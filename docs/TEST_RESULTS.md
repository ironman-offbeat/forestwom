# 테스트 결과

검증일: 2026-11-24 (KST). 환경: Windows, Node.js 24.18.0, Chromium 159 (Playwright).

## 자동 검증

| 항목 | 결과 |
| --- | --- |
| `npm test` | 36개 통과 |
| `npm run test:e2e` | 실제 Chromium 브라우저 시나리오 9개 통과 |
| `npm run build` | TypeScript 검사 및 정적 빌드 통과 |
| `npm audit --omit=dev` | 검사 시점 알려진 운영 의존성 취약점 0개 |

### 브라우저 시나리오

1. 가상 PDF 로드 → 원본 렌더링 → 7개 수치 확정 → 법령 게이트 → 검산 → 담당자 기록 → 인쇄 PDF 생성. 외부 네트워크 요청 0, localStorage/sessionStorage/IndexedDB 기록 0. 새로고침 시 자료 소멸 확인.
2. 미달 PDF의 조경 50㎡, 식재 45㎡, 자연지반 10㎡ 부족 표시.
3. 상충 PDF의 대지 1,000㎡/1,200㎡ 후보와 출처 페이지 모두 보존.
4. 텍스트 없는 스캔 모사 PDF 및 혼합 PDF 검토 보류.
5. 손상 PDF 명시적 오류.
6. 새 도면 추가 시 기존 확정 및 적용 범위 확인 해제.
7. 390px 모바일 화면에서 가로 넘침 없음. 최초 실패를 확인하고 grid 최소폭을 수정한 뒤 재검증.
8. 읽기 실패 문서를 검토에서 조용히 누락시키지 않으며, 정상값을 모두 확정해도 보류 유지. 초기화 후 회복.
9. 한글 가상 PDF의 CMap 기반 문자 추출·렌더링 및 검산. CMap·표준 폰트·WASM을 같은 정적 호스트에서 제공.

### 단위 테스트

연면적 1,000/2,000㎡ 경계, 대지 200/300㎡ 경계, 의무면적 기반 분모, 미세 미달값, 잘못된 숫자 형식·누락값·음수, 존재하지 않는 근거 페이지, 스캔 혼합, 미래·오래된 확인일, 과거 적용기준일, 미확인 게이트, 옥상·벽면 제외, 면적 포함관계, 상충 후보 보존 및 단위 없는 숫자 배제.

## 시각 검증

- 앱 초기 화면을 별도 인앱 브라우저로 확인.
- 한글 가상 PDF가 실제 원본 대조 화면에 정상 표시됨을 스크린샷으로 확인.
- 브라우저가 출력한 3페이지 의견서 PDF를 이미지로 렌더링하고 전체 페이지 확인. 한글, 표, 계산 근거, 보류사항, 담당자 기록 및 이력의 겹침/잘림 없음.
- 스크린샷과 출력 PDF는 `test-results/`에 생성되는 비커밋 테스트 산출물이다.

## 검증 한계

- 실제 민원자료·기관 업무망·한글 CAD 도면의 다양한 글꼴과 스캔 품질은 검증하지 않았다.
- 텍스트가 일부만 있는 이미지 도면은 단순 글자 수로 완전히 분류할 수 없다. 원본 대조가 필수다.
- 스캔 모사 샘플은 텍스트 없는 도형 PDF로, 실제 스캐너 이미지의 품질이나 OCR 정확도 검증을 뜻하지 않는다. 이번 버전은 OCR을 수행하지 않는다.
- 브라우저 테스트는 가상 입력 기준이며 법령·특례의 완전성, 기관 승인, 전자결재 보안성을 증명하지 않는다.
- PDF.js 포함 주 번들 약 687kB, worker 약 1.27MB의 크기 경고가 있다. 빌드 실패는 아니며 로컬 문자·렌더링 기능을 위해 포함한다.
- 원격 CI·배포 결과는 GitHub Actions 실행 기록을 기준으로 확인한다.
