# Forestwom 2차 작업계획 — 2026-11-25 수정

최신 요청에 따라 아래 구현 범위를 적용합니다. 이전의 이용자별 Google 로그인 계획은 소유자 1회 인증 방식으로 대체합니다.

1. 실험 전용·실사용 금지 문구와 등록 확인 체크박스를 제거하고, PDF 등록 → 원본 대조 → 수치 확정 → 의견서 확인 → 저장 순서를 안내합니다.
2. 로컬 PDF.js 판독과 검산 규칙·최신성·담당자 확인을 유지합니다. 실제 미확인 자료와 자동 검산 범위는 표시합니다.
3. 한글 글꼴을 포함한 의견서 PDF를 브라우저에서 생성합니다. PDF 출력 코드와 글꼴은 다운로드/저장 시 불러옵니다.
4. 기존 Vercel 프로젝트에 소유자 OAuth 서버를 추가합니다. 이용자는 로그인하지 않습니다. GAS·유료 AI API를 추가하지 않습니다.
5. 전용 Drive 폴더에 `[날짜] 도면 이름 · 시간-고유번호` 저장본을 추가합니다. 원본 PDF·의견서 PDF·복원용 JSON을 묶고 이전 저장본을 보존합니다.
6. 저장소 보기는 Drive로 바로 이동합니다. 다시 열기는 완료된 저장본 목록에서 선택하여 원본과 검토값을 복원합니다. 공개 편집을 고려하여 모든 확인·승인은 다시 받습니다.
7. 파일 크기·형식·폴더 경계·세션 서명·완료 검증·원본 해시를 확인합니다. 실패한 저장을 완료로 표시하지 않습니다.
8. 규칙 및 서버 단위 테스트, 실제 브라우저 PDF 출력·저장·복원 테스트, 한글 PDF 렌더링을 확인합니다. 실제 계정 테스트와 모의 테스트를 구분합니다.
9. GitHub에 커밋·푸시하고 Vercel 및 Pages 배포를 확인합니다. 소유자 연결 단계가 남으면 실제 저장 미검증 상태를 명시합니다.

## 사용자 직접 단계

소유자의 Google OAuth 승인 및 Vercel 비밀 환경 변수 설정이 필요합니다. [연결 안내](GOOGLE_DRIVE_SETUP.md)에 절차를 기록합니다. 채팅 연결 도구의 인증은 배포 앱에 복사할 수 없습니다.

## 완료 기준

- 새 안내 문구 및 저장·다시 열기·저장소 보기 버튼 표시.
- 실제 한글 PDF 생성과 시각 확인.
- 원본·메모·근거 페이지 복원, 변경된 원본 거부, 재검수 상태로 복원.
- 테스트 통과, 커밋 원격 반영, 운영 웹앱/API 응답 확인.
- 소유자 연결 후 실제 Drive 왕복 테스트는 별도 확인 항목으로 유지.
