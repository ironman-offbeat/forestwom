# Forestwom 작업계획서

작성일: 2026-11-24 (대한민국 표준시). 대상: ironman-offbeat/forestwom.

## 사전 확인

- 원격 저장소는 공개 저장소이며 최초 확인 시 비어 있었다.
- 프로젝트 sources 폴더에는 파일이 없었다. 기존 프로젝트 원문·정오표는 확보되지 않았다. 참조 대화 10턴 조회 결과 첨부파일 없음. 기존 자료를 검증 완료한 것으로 간주하지 않는다.
- 참조 대화의 영구 학습·완전 자동 판독·무료 운영에 대한 단정은 구현 근거로 사용하지 않는다.
- GAS, 서버 업로드, 유료 AI API, 자동 법적 승인, 실제 민원자료 사용을 제외한다.

## 구현 순서와 완료 기준

1. 공식 법령 출처·시행일·상충 및 미확인 사항을 별도 장부로 기록한다. 구 조례와 현행 확인본을 혼용하지 않는다.
2. React/TypeScript 정적 앱을 구축한다. PDF.js와 worker는 빌드에 포함하며 외부 CDN을 사용하지 않는다.
3. 복수 PDF를 메모리로만 읽고 페이지별 텍스트·원본 렌더링·수치 후보를 제공한다. 텍스트 부족 페이지는 판독 보류한다. 이번 버전에서는 OCR을 제공하지 않는다.
4. 후보 값은 자동 확정하지 않는다. 파일·페이지·발췌문을 보존하고 담당자가 값을 수정하고 원본 확인 사유를 입력한 후 확정한다. 충돌 후보는 모두 제시한다.
5. 좁은 범위의 일반 건축물 면적 검산을 구현한다. 대지 300㎡ 이상, 면제·특례 없음, 옥상·벽면 산입 없음으로 제한한다. 그 밖의 경우 자동 판정을 보류한다.
6. 법령 확인일, 적용기준일, 예외·상충 규칙 검토, 담당자 검토를 필수 단계로 구성한다. 수정 시 확정과 담당자 검토를 무효화한다. 법령 확인 유효기간 30일은 제품 운영 정책이며 법정 기간이 아니다.
7. 출처·수정값·보류사항을 포함한 의견서 초안을 화면 및 인쇄/PDF 저장으로 출력한다. 최종 협의 회신·승인 문서로 표시하지 않는다.
8. 가상 정상/미달/불일치/스캔/혼합/손상 PDF와 경계값 단위 테스트, 실제 브라우저 흐름 테스트, 외부 전송·저장 검사, 빌드 검증을 수행한다.
9. 계획·코드·법령 검증 장부·테스트 결과를 커밋하고 원격 반영 SHA를 확인한다. 정적 배포용 GitHub Actions 설정을 제공한다.

## 데이터 및 배포 정책

- 비식별 또는 완전 가상 자료만 허용하는 사전 동의. 기관 보안 정책 검토 전 실자료 사용 금지.
- PDF, 추출 텍스트, 검토값은 localStorage/IndexedDB/서버에 저장하지 않는다. 새로고침하면 사라진다. 인쇄 및 사용자의 PDF 저장은 명시적 사용자 동작이다.
- GitHub에는 코드와 생성된 가상 자료만 커밋한다. 저장소 공개 여부와 Pages 운영비·한도는 계정 정책에 따르며 무료를 보증하지 않는다.
- 기존 자료·정오표 수령, 기관 보안 승인, 최신 법령 및 부칙·지구단위계획·특례 확인 전까지 실무 서비스로 전환하지 않는다.
