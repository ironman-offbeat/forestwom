# 법령 검증·상충 규칙 장부

검증일: 2026-11-24, 규칙 버전: `2026-11-24.experimental.1`.

**공식 본문에서 확인한 제한적 계산 규칙이다. 실제 사건의 적용 법령·경과조치·지구단위계획까지 확정한 법률 의견은 아니다.** 법령은 실시간 갱신하지 않는다. 담당자는 사건마다 원문 확인일과 적용 사유를 기록한다.

## 승인 및 최신성 정책

- 원본 대조 없는 추출 후보, 출처 페이지 누락, 텍스트 부족 페이지, 읽기 실패 파일, 잘못된 수치, 포함관계 불일치는 검산 보류.
- 법령 확인일은 오늘 이하이면서 30일 이내. 이는 법정 유효기간이 아니라 실험용 앱의 운영 정책이다.
- 사건 적용일은 2025-03-10 이후부터 오늘까지. 이전 사건은 별도 규칙 버전이 필요하다.
- 담당자 검토자·메모 입력 후 초안 검토 기록 가능. 수치/근거/사유/법령/메모/자료가 바뀌면 기록 해제.
- 이 게이트는 인증된 전자결재·접근통제 시스템이 아니다. 사용자가 기재한 실험용 자기확인 기록이다. 기관 승인 절차를 대체하지 않는다.
- 어느 화면·출력물도 최종 적합, 면제 확정 또는 법적 승인으로 표시하지 않는다.
